# 0005 Shared Baseline Through Project Instructions

Status: Accepted

Date: 2026-11-05

## Decision

Keep the common, always-applicable agent baseline in `COMMON.md`. Each project adopting the shared guidance must require agents to read it through its `AGENTS.md`. Put task-specific guidance in skills, loaded when the task calls for them.

## Context

The baseline needs to apply at the start of every project session. Project instructions provide the entry point for both supported runtimes; skills are suited to guidance needed for particular kinds of work.
