# Standard Tools Skill

How to get `agt` was written out in four places: `COMMON.md`, `baseline:refresh`, `baseline:git` and `swift:validation`. The git skill reached into the refresh skill's folder for `ensure-agt.sh`, the validation skill carried its own copy, and `agt refresh` checked the copies for drift. The git and validation skills disagreed about a blocked install. Several skills also told agents to check `--help` for subcommands and options added in particular releases. Mint, ReleaseTools and SwiftWorkflowBuilder had no guidance beyond `COMMON.md`'s session-start install.

`baseline:tools` now covers all four tools: what each is for, how each is installed with Mint, updating AgentTools and ReleaseTools at the start of every session, finding them in `~/.mint/bin`, and a blocked install, where the agent asks for approval for that one `mint install` or asks Sam to run it, and otherwise carries on with the installed tool and reports it. Skills name AgentTools or `agt`, which brings in the tools skill, and assume the latest release; references to older releases are gone. `COMMON.md` keeps one line pointing to the session-start update.

`ensure-agt.sh` is deleted, with its copy. It solved a bootstrap that only happens when a machine is set up, and the README now gives the two commands for that: `brew install mint` and `mint install elegantchaos/AgentTools`. A machine without Mint is reported to Sam, not set up by an agent. AgentTools Owns Supporting Commands (0004) is revised to say so, and AgentTools drops the drift check for the copies in the same change. Baseline plugin 0.8.38, Swift plugin 0.12.2.
