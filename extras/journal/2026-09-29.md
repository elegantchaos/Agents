# 2026-09-29

## `agt` becomes the only dependency

- Merged [#6](https://github.com/elegantchaos/Agents/pull/6) after AgentTools 3.8.0 shipped. `scripts/refresh` and `scripts/configure-sandboxes` are gone; `agt refresh` and `agt sandbox configure` replace them.
- Review fixes before merging:
  - the README tells the user to add `~/.mint/bin` to `PATH`;
  - `swift:validation` assumes AgentTools 3.7 or later, and its sandbox recovery has the agent run `ensure-agt.sh --update`, then give the user the absolute path for `sandbox configure`;
  - the Python pin was dropped from `.tool-versions`.
- `ensure-agt.sh` bootstrap policy, confirmed: with Homebrew present it may install Mint and then AgentTools; with Homebrew missing it stops with a clear error. It never prompts. A future `xpkg-agents` Homebrew package may take over installing `agt` and this repository.

## Refresh

- A baseline refresh found stale `ruby`, `swift:language` and `swift:validation` entries in `AGENTS.md`. The repository has no Ruby code, and its Swift code moved to AgentTools. Removed in [#7](https://github.com/elegantchaos/Agents/pull/7).
- The runtime rules pass was not applied. Claude Code's auto mode blocked edits to the Codex approval rules as self-modification.
- Proposed, not applied:
  - promote `xcrun simctl` (`boot`, `bootstatus`, `install`, `io`, `launch`, `list`, `shutdown`) and `xcrun xcresulttool get` into `xcode.rules`;
  - drop the one-off and machine-specific entries in `default.rules`;
  - run `agt rules sync`, since the runtime `misc.rules` lacks `ps` and `true`.

## Under consideration: auto modes instead of approval rules

- Sam is considering standardising on Claude Code's auto mode and Codex's auto-review, which would make the rules half of the refresh (`agt rules`, `default.rules` triage) obsolete. Codex prefix rules in particular have proved unreliable. Decision deferred.
- Research summary:
  - Both vendors say their reviewer is not a security boundary.
  - Anthropic publishes a 17% false-negative rate on real dangerous actions for auto mode, and closed a working prompt-injection RCE chain (Rehberger, 60–80% success) as out of scope.
  - Codex auto-review only reviews sandbox-boundary crossings.
  - Independent write-ups agree that the sandbox, network egress limits and credential isolation are the real controls.
- If adopted:
  - keep `agt sandbox configure`, which both modes rely on;
  - retire `agt rules` from `baseline:refresh` and `COMMON.md`;
  - Codex prefix rules bypass the sandbox without review, so removing them is a safety gain, not a loss.
- Related open question: keeping SSH keys and the `gh` token usable by agents without being readable by them.
