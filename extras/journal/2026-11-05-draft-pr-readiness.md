# Draft PR Readiness

Sam noted that Copilot automatically reviews a PR only once by default, so an early ready-for-review signal can spend that review on incomplete work. The Git skill now creates PRs as drafts and offers to mark them ready when the current task, intended work and validation are complete. The agent waits for Sam to agree before changing the state. This supersedes the ready-by-default guidance recorded in [Reviews Assess Design Consequences](2026-10-28-review-design-analysis.md). Baseline plugin version: 0.8.32.

Sam clarified that the roadmap workstream table is for current state and return points, not a history. Removed completed change narratives from that table while retaining the open evaluation, decision candidate and validation return point.
