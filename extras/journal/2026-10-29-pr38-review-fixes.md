# PR #38 Review Fixes

Assessed [Claude's review at 806c375](https://github.com/elegantchaos/Agents/pull/38#pullrequestreview-5700727593) against the current guidance and companion AgentTools implementation.

- **Merge prerequisite:** AgentTools must be released with the new commands before Agents #38 merges. COMMON.md is loaded directly from this checkout, so delaying plugin installation does not delay activation. The roadmap and PR description name this order explicitly.
- **Bootstrap recovery:** when command help is missing, each owning workflow runs its `ensure-agt.sh --update` once, uses the returned executable path and rechecks. Only an unresolved gap is reported. The helper itself is unchanged, and a blocked update still uses the runtime's supported approval flow.
- **Approval rules:** the installed Codex CLI 0.165.0-alpha.1.2 reports `allow` for bare `agt prepare` and `agt validate` against the installed tools.rules. The absolute source executable used in integration checks has no match in that standalone rule check. [OpenAI's rules documentation](https://learn.chatgpt.com/docs/agent-configuration/rules) defines allow as outside-sandbox execution without prompting; [auto-review documentation](https://learn.chatgpt.com/docs/sandboxing/auto-review) distinguishes standing permission from a request handled by the reviewer. Sam explicitly approved removing the one blanket `agt` allow rule at the source. No installed rules, sandbox configuration or unrelated command approvals were changed. Apply the generated-rule refresh only during the normal rollout.
- **Auto approval:** Sam confirmed both runtimes use automatic approvals. This does not make allow rules redundant: they can short-circuit review. [Claude's documentation](https://code.claude.com/docs/en/auto-mode-config#route-all-shell-commands-through-the-classifier) says some allow rules remain effective in auto mode unless classifyAllShell is enabled. That effective Claude setting was not inspected here. Guidance uses the runtime's approval process and does not require another human confirmation after delegated review authorises an action.
- **Evidence correction:** earlier journal wording that calls the Codex integration sandboxed is too strong. The recorded commands succeeded under the session's active execution policy, but per-invocation sandbox enforcement was not independently established by command success or the nested-sandbox error. This affects the claimed sandbox coverage, not the recorded preparation/build/test outcomes. Keep actual Claude and verified runtime-sandbox acceptance as outstanding work.
- **Ownership and duplication:** baseline Git owns worktree creation, its bootstrap recovery and authorization. Swift validation defers to it for new worktrees and owns existing-checkout preparation. The journal index separator now follows the existing colon convention. No new bootstrap-script copies were added.

Decision 0010 was approved separately by Sam and is recorded in AgentTools. The broader historical proposal to replace the rules system, and unrelated Git/legacy-tool approvals, remain outside this focused change.
