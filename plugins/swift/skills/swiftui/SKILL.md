# SwiftUI

- Use the project's deployment targets and available SDK APIs to choose view and data-flow patterns.
- Distinguish framework correctness and accessibility requirements from architectural or stylistic preferences. Preserve explicit project conventions.
- Keep Xcode previews and IDE tools conditional on availability. Report gaps in visual verification when those tools are unavailable.
